# Strict Git Policy

## 🛑 ABSOLUTE RULE — NEVER GIT ADD, COMMIT, OR PUSH WITHOUT EXPLICIT PERMISSION
- **NEVER** run `git add`, `git commit`, or `git push` autonomously or automatically.
- **NEVER** stage files or create commits on your own under ANY circumstances.
- You are ONLY permitted to run read-only inspection commands:
  - `git status`
  - `git log`
  - `git diff`
- Commits and pushes must be done manually by the user, or only when the user explicitly prompts: "commit this" or "push to github".
